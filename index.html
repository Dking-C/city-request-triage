How the workflow runs

Each stage has a defined input, decision, and outcome.

1Ingest

Vercel fetches a small sample from NYC 311 server-side.

2Validate

Check request ID, category, date, and borough; flag gaps.

3Route + prioritize

Apply transparent keyword rules and assign a demo response target.

4Review + report

Keep exceptions visible; export the work queue for follow-up.
